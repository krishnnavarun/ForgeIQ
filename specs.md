**Version:** 1.0
**Status:** Development Specification

---

# 1. Product Overview

ForgeIQ is a multi-tenant engineering intelligence and operations platform that connects software development activity, project execution data, engineering metrics, and AI-powered analysis into a unified workspace.

Modern software teams use multiple tools:

* GitHub
* issue trackers
* pull requests
* code reviews
* project boards
* CI/CD systems
* communication tools
* documentation systems

The information generated by these tools is fragmented.

ForgeIQ creates an intelligence layer over these systems.

The platform collects permitted engineering activity, normalizes the data, calculates engineering metrics, provides organization-aware dashboards, and uses AI to generate grounded insights.

The platform is designed to help engineering teams answer questions such as:

* What is happening across our projects?
* Which projects are at risk?
* Which pull requests are becoming bottlenecks?
* Where are review delays occurring?
* How quickly are issues being resolved?
* How is delivery progressing?
* What changed during the current sprint?
* What should the engineering manager investigate?

ForgeIQ is an analytics and decision-support platform.

It does not replace engineering managers or automatically evaluate individual developers for employment decisions.

# 5. Multi-Tenant Architecture

ForgeIQ must support multiple organizations.

Example:

```text
ForgeIQ
│
├── Organization A
│   ├── Admin
│   ├── Managers
│   └── Developers
│
├── Organization B
│   ├── Admin
│   ├── Managers
│   └── Developers
│
└── Organization C
    ├── Admin
    └── Developers
```

Organizations must be isolated.

A user from Organization A must never access Organization B's private data.

# 33. Organization Isolation

Every organization-scoped query must enforce organization ownership.

Never rely only on:

```text

```

The backend must verify that the requested project belongs to the authenticated user's organization.

Conceptually:

```text
authenticatedUser.organizationId
        ↓

        ↓
must match
```
